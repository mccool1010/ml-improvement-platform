# Data directory

Nothing here is committed except this file and the directory markers. All data is
reproducible from `scripts/download_data.py`.

| Directory | Contents |
|---|---|
| `raw/` | The register exactly as downloaded, checksum-verified. Never edited. |
| `interim/` | Intermediate artifacts from exploration. Safe to delete. |
| `processed/` | Cleaned, labelled, split-ready data. Regenerated by the pipeline. |

The raw file is `SBAnational.csv`, 179,430,516 bytes, SHA-256
`0359128a0b7599e83e4c2e4dcdd781d9121a765237f98d9f0ec1ab3e7c522548`. Every training
run verifies that checksum and records it, so a changed upstream mirror fails the
run rather than silently altering results.

See [../docs/data.md](../docs/data.md) for the schema, labelling rule and known
data quality issues.
